# 구현 및 검증 기록

## 구독 AI 모드 이미지 연결 보완

- 수동 모드에 사진 번호·원본 파일명·설명 입력과 첨부용 파일 다운로드를 추가했다. 요청문과 다운로드 파일명을 일치시키고 저장 이미지 ID로 결과를 연결한다.
- API 모드의 기존 썸네일·요청 형식은 보존하며 실제 UI 렌더 테스트로 모드별 표시를 검증한다.
- 준비·일반 임시저장 시 사진 순서를 기록하고 복원 시 정렬한다. 이미지 압축 중 요청 준비·저장·가져오기를 막고 초기화·계정 변경·다른 글 불러오기 이전의 압축 결과를 폐기한다.
- 이미지 메타데이터·수동 요청문·다운로드 UI·모드별 UI·업로드 경합을 자동 검증한다. 실제 브라우저 다운로드·외부 AI 사진 첨부와 네이버 입력·저장 검증은 미수행이다.
- 최종 자동 테스트 49개, 타입 검사, 변경한 수동 작성 Hook·UI 및 신규 테스트의 ESLint, 프로덕션 빌드를 통과했다.
- 새 DB 마이그레이션·외부 서비스 발급·확장 프로그램 런타임 또는 ZIP 변경은 필요하지 않다.

## 구독 AI 모드 전환

- 기본 화면을 요청문 준비·복사 → 사용자의 AI 서비스에서 직접 생성·사진 첨부 → JSON 붙여넣기/파일 가져오기 → 미리보기·네이버 전송으로 변경했다.
- 상단 모드 선택의 API 버튼은 `API_MODE_ENABLED=false`로 비활성화했으며 기존 API 생성·키·모델 코드는 보존했다. 기본 모드에서는 AI API나 모델 목록을 호출하지 않는다.
- 외부 결과 가져오기는 인증·소유권·DRAFT 상태·서식 문서·이미지 ID를 검사한다. 실패 시 초안을 유지하고 동시 저장으로 완료된 문서를 덮어쓰지 않는다.
- 입력 변경·계정 전환·이전 파일 읽기의 화면 덮어쓰기를 방지하고 토큰 갱신 때는 준비한 요청문을 유지한다.
- 최종 자동 테스트 38개, 타입 검사, 신규 모듈 및 변경한 수동 작성 UI·API의 ESLint 검사, 프로덕션 빌드를 통과했다. 테스트에는 실제 가져오기 라우트를 경계만 대체해 실행하는 소유권·경합 검사와 실제 UI 렌더의 API 버튼 disabled·텍스트 이스케이프 검사가 포함된다.
- 새 DB 컬럼이나 확장 프로그램 런타임 변경은 없다. 기존 document 마이그레이션·Supabase 설정은 필요하다. 실제 사용자 로그인·클립보드·외부 AI 생성·네이버 입력/저장 검증은 이번 전환에서도 미검증이다.

아래 기록은 앞서 구현한 API·확장 프로그램 검증 이력이다.

## 반영 사항

- 버전 1 서식 문서, 서버 검증, 기존 일반 텍스트 호환, 웹 미리보기
- 인증된 상세 조회와 문서 없는 경량 목록, API Key 서버 전용 접근
- 토큰 없는 웹 bridge, 정확한 웹 origin 등록, 세션 임시 보관
- 네이버 편집 영역 탐색, 서식 붙여넣기, 별도 이미지 첨부 시도·부분 실패·수동 다운로드
- 개인정보를 제외한 에디터 진단, 수동 임시저장·재열기·발행 안내
- DB 마이그레이션, 환경 변수 예제, 확장 패키징 스크립트

## 코드 검증

TypeScript 검사와 최종 프로덕션 빌드가 통과했다. 신규 문서·생성·인증 모듈, 변경한 생성·조회·키·모델 API, 신규 전송·미리보기 UI, 확장 프로그램 및 테스트를 대상으로 한 ESLint 오류는 0개다. 전체 ESLint에는 기존 Hook·컴포넌트 등의 오류가 남아 있어 전체 통과로 보고하지 않는다. 기존 HEAD와 비교한 `useHome.ts` 오류는 21개에서 20개, `Header.tsx`는 기존 1개로 동일하며, 생성·조회·키·모델 API 오류는 0개로 감소했다.

`npm test`의 18개 테스트가 통과했다. 빈 줄·공백·기존 이미지 표식 호환, 혼합 서식 이스케이프, 잘못된 문서·이미지 참조 거부, 중복 요청 락·예외 해제, 발신자·origin 검사, 서식 번짐 감지, 개인정보 없는 진단, 빈 에디터 placeholder 제외를 검증했다.

`npm run package:extension`으로 `public/blog-auto-write-extension-v1.0.0.zip`을 생성했다. ZIP의 명시적 허용 실행 파일 10개와 원본 소스의 SHA-256이 모두 일치한다. 비밀 환경 파일이나 테스트는 패키지에 포함하지 않았다.

설정이 없는 환경에서 프로덕션 서버 HTTP 확인 결과 대시보드는 200, 글 API는 환경 변수 설정 안내와 함께 503을 반환했다. 이는 실 DB 연결·로그인·AI 생성 검증을 대체하지 않는다. 빌드 시 환경 변수 누락 경고도 의도대로 표시된다.

## 실제 환경에서 남은 확인

- Supabase SQL 마이그레이션 실행 및 인증·API Key·신규 생성·기존 글 조회
- 실제 AI 모델 응답과 문서 검증, 배포 환경의 `after()` 지원·실행 시간 제한
- Chrome 확장 로드·운영 origin 허용·웹 전달·디버거 권한 알림
- 네이버 로그인 후 제목·본문·공백·빈 줄·혼합 서식 입력
- 이미지 업로드·HTTPS 이미지 로딩·원래 위치, 실패·부분 성공 안내
- 네이버 임시저장 후 재열기에서 텍스트·서식·이미지 보존

실제 네이버 로그인·저장 환경이 없어 최종 수용 기준은 미검증이다. 요청 접수·미리보기·DOM 반영을 저장 완료로 간주하지 않는다. 사용자는 웹 설정에 AI Key를 직접 등록하고 환경 변수는 로컬 또는 배포 설정에 입력한다. 비밀값을 채팅으로 전달할 필요는 없다.
