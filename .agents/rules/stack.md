- Rule1(안전성 최우선): 유저의 개인 네이버 계정 정보나 AI API Key가 로그에 노출되거나 외부로 유출되지 않도록 전 과정에서 Secure Mode를 활성화하고, .env 환경 변수 처리를 철저히 한다.
- Rule2(점진적 개발): 한 번에 거대한 코드를 짜지 않는다. 웹 프론트엔드, 웹 백엔드, 크롬 익스텐션, DB 설계를 철저히 분리하여 모듈화된 코드를 작성한다.
- Rule3(네이버 DOM 변화 대응): 네이버 스마트에디터 ONE의 HTML 구조는 언제든 바뀔 수 있으므로, 익스텐션 코드 작성 시 셀렉터(Selector) 구조를 설정 파일(config.json)로 분리하여 유지보수가 쉽도록 설계한다.
- Rule4(상호 교차 검증): 개발 에이전트가 코드를 작성하면 반드시 테스터 에이전트의 검증(Review)을 거쳐야만 마스터 에이전트에게 최종 승인을 요청할 수 있다.
