# UXD: 웹과 확장 프로그램 UI

## 책임

사용자가 내용과 강조·글자색·밑줄을 확인하고 확장 프로그램으로 네이버에 옮길 수 있는 UI를 설계한다. 기존 Tailwind CSS와 반응형 구성을 따른다.

## 웹 대시보드

- 카테고리, 주제·가이드, 장소, 참고 글·기본 예시, 이미지, 임시저장·불러오기 흐름을 유지한다.
- 구조화 문서의 문단·빈 줄·혼합 서식·이미지 위치를 렌더링한다. 원본을 미리보기 과정에서 임의 변경하지 않는다.
- AI 서식과 실제 지원 범위를 보여준다. 수동 서식 편집 UI 추가는 별도 요구 확정 시 설계한다.
- 생성 대기·진행·완료·실패를 표시한다. 추정 진행률을 실제 처리율처럼 표현하지 않는다.

## 확장 프로그램

- 인증, 글 선택·조회, 제목·서식 요약, 전송과 결과 UI를 제공한다. PC 데몬 설치를 필수로 안내하지 않는다.
- 네이버 로그인 필요, 잘못된 탭, 에디터 준비, 입력 중·완료, 저장 검증 여부를 구분한다.
- 이미지·서식 일부 실패, 인증 만료, 미지원 문서 버전에 복구 방법을 제공한다. 원본을 유지하고 재시도 시 중복 삽입 위험을 알린다.
- 네이버에서 사용자 최종 확인·발행을 안내한다. 요청 접수만으로 등록·발행 완료라고 표시하지 않는다.

## 인계

영역별 컴포넌트와 PM 계약에 맞는 props·상태를 설계한다. 임의 원시 HTML을 그대로 렌더링하지 않는다. 화면·상태별 마크업, 연결점, 오류·접근성 확인 결과와 경로를 FSD에 전달한다.
