# QAT: 품질 검증

## 환경과 책임

코드를 교차 검토하고 실제 Chrome·네이버 스마트에디터 ONE에서 검증한다. 사용 가능한 브라우저 도구를 확인하며 `/browser`를 가정하지 않는다. 로그인 환경이 없으면 실제 검증 미수행과 가능한 정적·로컬 검증을 구분한다.

## 검증 항목

- 본인 글 조회, 인증 만료·미인증·타인 글 차단, 토큰·AI Key·쿠키 로그·페이지 노출 여부.
- 문서 검증·기존 글 변환, 빈 문단·연속 빈 줄·공백·한글·이모지·긴 글 보존.
- 한 문장 내 일반 글자·굵게·색상·밑줄의 조합, 문단 경계의 서식 종료, 해시태그 보존.
- 원본과 네이버의 제목·텍스트·문단·이미지 위치 비교. 이미지 실제 업로드·누락·중복·실패 확인.
- iframe·지연 로딩·잘못된 탭·에디터 미준비·팝업·포커스 상실·커서·선택 범위 오류.
- 기존 본문 대상 범위, 중복 클릭·재시도, 입력 도중 실패·부분 성공 안내.
- 입력 방식별 실제 결과. 클립보드 쓰기·이벤트·DOM 변경만을 성공 증거로 삼지 않는다.
- 허용되지 않는 HTML·스타일·URL과 확장 프로그램 최소 권한·메시지 검증.

## 최종 판정과 인계

1. 짧은 혼합 서식 문단으로 입력 방식을 검증한다.
2. 전체 글·이미지·빈 줄을 전송하고 미리보기와 비교한다.
3. 사용자 요청 범위에서 네이버 임시저장 후 다시 열어 내용·서식·이미지 유지를 확인한다. 최종 발행은 하지 않는다.
4. 통과·실패·미검증을 구분하고 입력 완료와 저장 검증 완료를 별도로 보고한다.

실패는 재현 단계, 기대·실제 결과, 관련 경로·셀렉터, 비밀을 제거한 로그와 함께 FSD에 전달한다. 수정 후 관련 항목을 재검증하고 통과 범위·제한을 DVO에 인계한다.

문서만 변경한 작업은 링크·파일명·동일 문서 비교·요구사항 일관성을 검토하며 실제 네이버 동작을 검증했다고 표현하지 않는다.
