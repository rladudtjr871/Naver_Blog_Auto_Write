# AI 네이버 블로그 작성 도우미

사용자가 구독 중인 AI 서비스에서 글을 생성하고 결과를 웹으로 가져온 뒤 Chrome Manifest V3 확장 프로그램으로 네이버 스마트에디터 ONE에 옮깁니다. 자동 발행하지 않으며 사용자가 네이버에서 내용을 확인하고 저장·발행합니다.

## 작성 모드와 기본 사용 순서

상단의 **구독 AI에서 작성**이 기본 모드입니다. **API로 작성** 버튼은 비활성화되어 있습니다. 기존 OpenAI·Gemini API 코드와 저장 글은 보존하지만 현재 화면에서 API 생성을 실행하지 않습니다.

1. 로그인 후 카테고리, 토픽·가이드, 장소, 예시 글, 이미지를 입력합니다.
2. 작성 요청을 준비합니다. 입력과 이미지를 임시저장하고 저장된 이미지 ID를 포함한 요청문을 만듭니다.
3. 요청문을 복사해 사용자가 선택한 ChatGPT·Gemini·Claude 등의 웹사이트에 직접 붙여넣습니다. 준비 화면의 사진을 내려받아 표시된 첨부 파일명 그대로 해당 AI 대화에 직접 첨부합니다. 요청문 복사만으로 이미지 파일이 첨부되지는 않습니다.
4. AI가 반환한 **전체 JSON**을 결과 입력란에 붙여넣거나 JSON 파일로 가져옵니다. JSON 코드 블록도 허용하지만 일반 텍스트·HTML은 가져오지 않습니다.
5. 가져오기 성공 후 제목·본문·서식·이미지 위치를 미리보기로 확인하고 확장 프로그램으로 전송합니다.

작성 요청 준비 후 입력이나 이미지를 변경했다면 요청을 다시 준비하고 AI에게 다시 작성하도록 요청해야 합니다. 이전 요청의 이미지 ID를 새 요청과 섞지 마세요. 잘못되거나 잘린 JSON은 오류를 표시하고 기존 임시저장을 덮어쓰지 않습니다.

구독 AI 모드에서는 사진 번호·원본 파일명·선택 입력한 사진 설명으로 이미지를 구분합니다. 요청문의 `filename`은 내려받는 파일명(예: `01-외관.jpg`)이며, `imageId`는 결과 JSON을 저장 사진과 연결하는 값입니다. 파일명이 없는 이전 사진은 썸네일과 설명을 확인하세요. API 모드의 기존 이미지 UI와 요청 형식은 유지합니다.

이 모드는 우리 서버에서 AI API를 호출하지 않으며 AI API Key 등록도 필요하지 않습니다. 외부 AI 서비스 계정·구독·사용 한도는 사용자가 이용하는 서비스의 조건을 따릅니다. 로그인이나 구독만으로 무제한 생성이 보장되지는 않습니다. 설계와 입력 계약은 [구독 AI 작성 흐름](docs/subscription-workflow.md)을 참고하세요.

## 구성과 지원 범위

- Next.js App Router, React, TypeScript, Tailwind CSS 기반 대시보드 및 API
- Supabase Auth·PostgreSQL·Supabase SDK 기반 사용자별 글과 API Key 관리
- 구독 AI용 요청문과 결과 가져오기, 문단·굵게·글자색·밑줄·이미지 참조를 담은 버전 1 문서
- 기존 OpenAI·Gemini 서버 호출 코드 보존, API 작성 모드는 비활성화
- 웹 미리보기와 확장 프로그램이 동일 문서 사용, 기존 일반 텍스트 글 읽기 호환
- `extension/`의 Manifest V3 확장 프로그램: 웹 연결, 수신 글 확인, 네이버 탭 선택, 서식 있는 본문 입력

이미지는 현재 Base64 Data URL로 저장합니다. 확장 프로그램은 이미지 위치 표시와 다운로드를 제공하며, 실제 사진은 사용자가 표시 위치에 첨부해야 합니다. Python/Selenium 프로그램과 ZIP은 기존 자산으로 남아 있으나 새 확장 프로그램 사용에 필요하지 않습니다. Prisma 스키마도 있지만 실제 API의 주요 DB 접근은 Supabase SDK입니다.

**실제 네이버 입력·서식 유지·임시저장 후 재열기는 사용자 로그인 환경에서 검증해야 합니다.** 전송 접수나 화면 입력 완료가 저장 성공을 뜻하지 않습니다. 설계 계약은 [docs/extension-design.md](docs/extension-design.md)를 참고하세요.

## 웹 설정

1. Node.js 20.9 이상과 npm을 설치하고 `npm install`을 실행합니다.
2. `.env.example`을 `.env.local`로 복사하고 Supabase 프로젝트의 URL, anon key, service role key를 직접 입력합니다. service role key와 `ENCRYPTION_KEY`는 서버 전용입니다.
3. `ENCRYPTION_KEY`는 정확히 UTF-8 32바이트의 무작위 비밀값으로 설정합니다. **기존 서비스에서는 기존 암호화 키를 유지해야 합니다.** 교체하면 저장한 AI Key를 읽을 수 없습니다. 기존 키가 없다면 웹 설정에서 AI Key를 다시 등록해야 할 수 있습니다.
4. 신규 DB는 [supabase_schema.sql](supabase_schema.sql)을 Supabase SQL Editor에서 실행합니다. 기존 DB는 [마이그레이션](supabase/migrations/202610160001_rich_documents.sql)을 실행합니다. 마이그레이션은 `BlogPost.document`와 기본 참고 글 테이블을 추가하고 API Key의 브라우저 직접 접근을 차단하며 기존 글을 변환하지 않습니다.
5. `npm run dev` 후 `http://localhost:3000`에 접속합니다. 회원가입·로그인하고 Supabase 이메일 확인을 사용한다면 확인 메일 인증도 완료합니다. 기본 구독 AI 모드는 OpenAI·Gemini API Key 등록이 필요하지 않습니다.

AI Key, service role key, 암호화 키를 채팅이나 소스에 붙여넣지 마세요. 환경 변수는 로컬 환경 파일 또는 배포 서비스의 환경 변수 화면에, AI Key는 웹의 설정 화면에 직접 입력합니다. `DATABASE_URL`, `DIRECT_URL`은 Prisma CLI를 사용할 때만 필요합니다. 실제 DB에 마이그레이션을 실행한 상태는 별도로 확인해야 합니다.

## 확장 프로그램 설치와 사용

1. Chrome 116 이상에서 `chrome://extensions/`를 열고 개발자 모드를 켭니다.
2. ‘압축해제된 확장 프로그램을 로드합니다’로 저장소의 `extension` 폴더를 선택합니다. 소스를 수정했다면 확장 관리 화면에서 새로고침합니다.
3. 로컬 기본 웹 주소는 `http://localhost:3000`입니다. 운영 웹은 확장 팝업의 ‘운영 웹 주소’에 정확한 HTTPS origin(예: `https://example.com`)을 넣고 ‘웹 연결 권한 추가’를 눌러 허용합니다. 연결 후 웹 탭을 새로고침합니다.
4. 구독 AI에서 생성한 JSON을 웹으로 가져오고 제목·본문·빈 줄·혼합 서식·이미지 순서를 미리보기로 확인한 다음 ‘확장 프로그램으로 전송’을 누릅니다. 기존 저장 글도 전송할 수 있습니다. 확장 프로그램에 API Key나 인증 토큰을 입력할 필요는 없습니다.
5. 같은 Chrome에서 네이버에 직접 로그인하고 블로그의 새 글쓰기 화면을 엽니다. 기존 제목과 본문이 없는 에디터를 사용합니다.
6. 확장 팝업에서 받은 글 제목과 ‘네이버 편집 탭’을 확인하고 ‘서식과 본문 입력’을 누릅니다. 개발자 도구는 닫고 입력 중 편집 화면을 조작하지 않습니다.
7. Chrome에 디버깅 권한 알림이 표시됩니다. 확장 프로그램은 실제 붙여넣기를 위해 선택한 네이버 탭에 디버거를 연결하며 작업 종료 시 해제합니다. 클립보드 내용도 교체됩니다.
8. 이미지가 있다면 ‘이미지 다운로드’로 받고 본문의 위치 표시를 참고해 네이버에서 직접 첨부합니다. 위치 표시를 정리한 뒤 제목·공백·빈 줄·서식·이미지 순서를 비교합니다.
9. 네이버에서 직접 임시저장하고 다시 열어 유지 여부를 확인한 다음 최종 발행합니다.

부분 입력 후 무작정 재시도하면 중복될 수 있습니다. 실패 안내를 확인하고 이미 들어간 내용을 정리하거나 새 빈 에디터를 연 뒤 다시 입력합니다. 네이버 DOM이 바뀌면 `extension/config.json`의 셀렉터와 실제 편집 영역을 점검해야 합니다. 서식이 사라졌다면 저장 성공으로 간주하지 말고 붙여넣기 호환성을 확인합니다.

## 검증 및 배포

`npm run lint`, `npx tsc --noEmit`, `npm run build`로 웹을 점검합니다. 문서 검증과 확장 프로그램의 실제 네이버 동작 검증은 별개입니다. 배포 환경에도 동일한 서버 환경 변수를 설정하고 DB 마이그레이션을 먼저 적용합니다. 서버리스 AI 작업은 플랫폼 실행 시간 제한의 영향을 받으며 폴링만으로 작업 지속을 보장하지 않습니다.

사용자 환경에서 필요한 준비는 Supabase 프로젝트·환경 변수·기존 서식 문서 DB 마이그레이션, 직접 사용할 AI 웹 계정, 네이버 로그인, 운영 시 웹 origin 권한 허용입니다. 구독 AI 모드 추가를 위한 새 DB 마이그레이션이나 확장 프로그램 재설치는 필요하지 않습니다. 네이버 앱 API 발급이나 별도 PC 자동화 서버도 필요하지 않습니다.
